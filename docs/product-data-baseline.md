# Product Data Baseline

검증일: 2026-07-30

제품 URL 확장 전에 현재 카탈로그 데이터의 최소 기준을 고정한다. 실제 출처가 없는 값은 추정하지 않고 `ON REQUEST` 상태로 유지한다.

## 최소 필드

| 필드 | 기준 |
|---|---|
| `c` | 제품/모델 식별자. 문의 payload와 일치해야 함 |
| `n` | 제품 유형 또는 구성 설명 |
| `s` | 외형 치수 또는 개구부 치수 |
| `g` | 조리/그릴 영역 치수. 미확정이면 `—` |
| `w` | 중량. 미확정이면 `—` |
| `img` | 대표 이미지 경로. 없으면 상세 URL 확장 전 보완 대상 |
| 문의 가능 여부 | 제품 배열이 문의 선택 맵에 포함되어야 함 |

## 현재 인벤토리

| 제품군 | 모델 수 | 핵심 사양 완비(`g`/`w`) | 대표 이미지 | 상세 페이지 |
|---|---:|---:|---:|---:|
| LGA | 15 | 11 | 8 | 1 |
| LGY Robata | 2 | 2 | 2 | 2 |
| LSO/LSV Professional Smokers | 8 | 7 | 7 | 0 |
| LSC/LGC/LOW Indoor | 5 | 5 | 4 | 0 |
| Accessories | 14 | 별도 기준 | 0 | 0 |

## URL 적용 가능 1차 후보

데이터와 상세 화면이 모두 준비된 모델부터 URL을 만든다.

- `LGY_610` — D300/D400 변형, 상세 화면 있음
- `LGY_840` — D300/D400 변형, 상세 화면 있음
- `LGA_J900_T` — 상세 화면 있음

## 보완 후 URL 확장 대상

- LGA: `LGA_1200_S`, `LGA_1200_T`, `LTR_5500_S`는 `g`/`w` 출처 확인 필요
  (`LGA_J900_T_NS`는 2026-08-11 오너 확인으로 `LGA_J1310_T`로 코드 정정, `g`/`w` 확정)
- Professional Smokers: `LSO_1400_PA`는 `g`/`w` 출처 확인 필요
- 모든 모델: 이미지 없는 모델은 대표 이미지 또는 의도적인 텍스트 카드 정책 결정 필요
- Accessories: 제품 코드 체계와 호환 모델 필드 추가 필요

## 판정

현재 데이터 수준에서 전체 모델 URL을 일괄 적용하지 않는다. 대표 3개 모델로 URL 구조를 먼저 검증하고, 누락 데이터가 보완된 제품군부터 순차 확장한다.
