# Representative Product Detail Enhancement Checklist

대상: `LGY_610`, `LGY_840`, `LGA_J900_T`

원칙: 확인된 제품 데이터만 사용하며 가격, 재고, 리뷰는 추정하거나 표시하지 않는다.

## 1. Product 구조화 데이터

- [x] 제품 정적 HTML에 JSON-LD가 서버 응답 단계부터 포함된다.
- [x] LGY 페이지는 `ProductGroup`, J900 페이지는 `Product`로 표현한다.
- [x] 브랜드와 제조사를 `Lamsturn`으로 명시한다.

## 2. 모델·제품군·치수·중량·제조 정보

- [x] 세 제품 모두 모델명과 제품군을 포함한다.
- [x] 확인된 외형 치수와 중량을 `QuantitativeValue`로 표현한다.
- [x] `Stainless steel 304`, 대한민국 제조 정보를 포함한다.

## 3. LGY D300/D400 변형

- [x] `LGY_610_D300`, `LGY_610_D400`을 개별 변형으로 구분한다.
- [x] `LGY_840_D300`, `LGY_840_D400`을 개별 변형으로 구분한다.
- [x] 변형별 깊이와 중량을 정확히 연결한다.

## 4. 제품별 문의 CTA

- [x] 제품 상세 상단 CTA가 해당 모델을 문의 목록에 추가한다.
- [x] 제품 상세 하단 CTA가 해당 모델을 문의 목록에 추가한다.
- [x] 중복 추가 없이 문의 폼으로 이동한다.
- [x] LGY 제품은 D300/D400 선택을 위해 깊이 선택 팝업을 제공한다.
